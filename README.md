# Supreme Model T‑X

**Supreme Model T‑X** is a proposed human-governed, multidisciplinary platform to benchmark, evaluate, and grade AI models. Its intended program includes subject-specific suites, structured model interviews, weighted scorecards, progressive milestones, and human oversight. Terminal-Bench is one potential terminal/coding evaluation track, not the platform's purpose.

This repository contains application and documentation artifacts, including earlier orchestration and DevOps-oriented planning. Those artifacts do not establish live production operation, benchmark results, customers, revenue, partnerships, or traction. See the [investor pitch](docs/pitch-deck.md) for status-qualified product direction.

## T‑Series Model Hierarchy

| Model | Name | Role |
|-------|------|------|
| **Model T‑101** | Evaluation engine | Planned model evaluation and structured scoring |
| **Model T‑201** | Human governance | Proposed guideline, review, and oversight processes |
| **Model T‑301** | Benchmark suites | Planned multidisciplinary tasks and benchmark adapters |
| **Model T‑501** | Evidence layer | Proposed reproducibility and audit evidence |
| **Model T‑X** | Flagship | Human-governed, multidisciplinary model evaluation |

These are product concepts and intended roles, not claims that the planned evaluator or councils are operational. See [`docs/brand.md`](docs/brand.md) for naming and visual identity.
